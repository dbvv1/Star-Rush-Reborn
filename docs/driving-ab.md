# 同弯驾驶 A/B（候选，不替换默认）

以海岸 380–660 m 连续左右弯比较一次完整的入弯、收漂喷射与碰撞恢复。两份使用相同原场景、车辆、相机和速度上限；不混入场景编排候选。

```sh
node tests/handling-ab-preview.mjs
```

Node 24；在浏览器所在机器运行。命令打印 `baseline`、`arcade-ab` 两个仅 loopback 地址，使用真实 Worker 和分别独立的内存 SQLite。正常菜单选择海岸／驾驶练习，使用默认追尾镜头、WASD、Shift、Q／空格。F2 仅辅助观察。Ctrl+C 关闭两份服务；不启动浏览器、不改安全配置、不部署。两份编译快照只在忽略的 `outputs/handling-ab/`，构建结束恢复默认生成物。

单独构建候选：`STAR_RUSH_HANDLING=arcade-ab npm run build`。回退：`unset STAR_RUSH_HANDLING; npm run build`。未知值拒绝。候选菜单明确标识，帮助文字与主动小喷规则一致。不要拿候选圈速覆盖正式最佳记录：使用两个独立临时地址比较。

## 首轮候选的完整变化

- **高速转向**：108 km/h 以下原样；以上仅把方向输入的渐入响应从 26/s 平滑减至最低 8/s，松键及反打消除原方向的阶段仍为 26/s，转入反方向后再渐入。普通最大 1.04 rad/s、漂移最大 1.80 rad/s 保留，不自动找回赛道中心。首版曾按速度压缩最大角速率，但真实主弯跟弯能力不足，已撤回；不能把输入过敏和转弯能力混为一项。
- **主动喷射**：重新踩油门不再消耗已获得小喷；Q／空格仍可双喷，E／C 和组合规则不变。收漂与重新加速不再共用一次性喷射输入。
- **贴墙恢复**：原接触冲量、反弹和外力撞击仍工作。只有实际接触护栏且继续向墙转向时逐渐抑制推进；转向量从 0.1 到 1 平滑增强，反打开始恢复推进，滤波中的向墙转向退去后完全恢复。每步按向墙的转弯加速度增加沿墙擦速（系数 0.65），仅一次，不随求解迭代倍增；没有额外固定冻结时间。轻擦且不向墙转向不额外固定扣速。

108 km/h、8/s、0.65 是本轮可撤回设计假设，不是公开参考的抄参或已通过主观验收的最佳值。沿墙明显降速只说明代价存在，不说明手感正确。

## 比较与撤回条件

正常驾驶到同一段，依次做中／高速轻点方向、起漂后松键重新踩油门再主动小喷、轻擦与更大角度撞墙后反打。观察能否预判修正幅度、喷射是否由玩家主动决定、轻失误是否仍易恢复，不能只看圈速。

若高速压缩使正常弯更难入弯或漂移失去控制权，若轻擦被过度制动、反打仍被粘住，或明确喷射让教学与实际不一致，撤回／修订候选而非改为默认。工程自动测试只约束有限值、旧默认、操作语义、完赛和恢复，不代替手感。Canvas 可核输入与轨迹；WebGL 观感、硬件性能和听感另验。
