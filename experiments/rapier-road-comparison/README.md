# Rapier 同弯驾驶对比 · 未采用

独立可操控候选：把 **Rapier 现成四轮射线车辆求解器**接到汐见海岸原有
`circuitRoad(s)` 的直道与首个连续弯（170–740 m），保留原车模和标准追尾
镜头。不是继续调整原平面单轨模型，也不是地平线代码／参数／质量的复刻。

**状态：默认未采用；生产构建已接旁置 `/rapier/`，网站上线以部署回执为准。完整同弯与主观手感未验收。**
正式 `/`、`/road`、`/legacy` 驾驶与 AI、幽灵、联网、排行榜和存档均不接入此求解器。
撤回须同步移除根构建的 Rapier 路由及子包构建调用；无数据迁移。

## 打开

需要 Node.js 24。先在仓库根目录安装原依赖，然后运行隔离子包：

```sh
npm ci
cd experiments/rapier-road-comparison
npm ci
npm test
npm run build
npm run dev
```

在**与服务相同执行环境**的浏览器打开 `http://127.0.0.1:4187/`。
`PORT=4188 npm run dev` 可换端口。此服务只有独立试验页面和静态资源，
没有正式产品路由或 API；不会启动浏览器、改变安全参数或部署站点。
构建只写本目录忽略提交的 `dist/`，不调用根 `build.mjs`。

| 操作 | 行为 |
|---|---|
| W / ↑ | 渐入油门；松键逐渐收油，不清车速 |
| A / D，← / → | 渐入、回正及随速转向限制 |
| S / ↓ / 空格 | 刹车优先，强制所有轮 `engineForce=0` |
| X | 独立倒车；仍向前时先制动 |
| R / 复位 | 回 170 m；重建刚体与车辆，清速度、力、轮转和悬挂缓存 |
| Esc / 暂停 | 停止 fixed-step，恢复不追赶隐藏时间 |
| 退出试验 | 释放 RAF、输入、Rapier 世界与渲染资源 |

窗口失焦或进入后台会暂停。翻覆／出界不会吸回轨道；用 R 显式复位。
WebGL2 不可用会显示错误，不把 Canvas 画面冒称为 Three 验收。

## 复用和改造边界

- 固定源与许可证见 [THIRD_PARTY_NOTICES](THIRD_PARTY_NOTICES.md)。
  Three 官方车辆示例固定 `f17eb5d6`，MIT；实际求解器是官方 npm
  `@dimforge/rapier3d-compat@0.21.0`，Apache-2.0，
  `js-v0.21.0` / `b716d375`，锁文件固定完整性。
- 复用官方 `createVehicleController`、四轮设置、悬挂／舵角／轮转读取模式；
  不移植 demo 的 mass 10、frictionSlip 1000、双时钟或每帧 .25 lerp。
- `generate.mjs` 直接读取冻结项目的原 spline、车身、驾驶员和车轮几何，
  不修改原作者资源。天空沿用已有 Kenney CC0 资源；无商业素材。
- 赛道简化为路面、原路缘高度、护栏和标线，不移植装饰或正式玩法。
  显示与碰撞使用同一组 1 m 索引连续 strip；每个护栏是一张连续网格，
  不用大量相邻独立盒体产生接缝。
- 原车 `.97` 缩放、默认追尾 back 8.5 / up 4.5 / look 10、FOV 62，
  航向阻尼 8/s、镜头位置阻尼 18/s 保留。低速无速度方向时以车头为回退。
  不追加视觉假侧倾；轮子实际消费悬挂、舵角和转动。

## 唯一物理所有者

```text
键盘／触控 → 本作轻输入层 → 每 1/120 秒：
  设置轮引擎力 / 刹车冲量 / 前轮舵角
  Rapier controller.updateVehicle(dt)
  Rapier world.step()
  只读 XYZ / quaternion / velocity / suspension
       ├─ 渲染插值与追尾镜头
       └─ 局部 world→s/l 投影、HUD 和顺序检查点
```

没有 `advanceRoadPose` / `resolveContacts`，没有路径吸附、车速方向强改、
强制扶正或自动瞬移。只有明确复位重建车体。投影不参与刚体积分；
顺序检查点只在局部连续前进且位于主路内时递增，无计分或保存功能。
长帧最多消费 .25 s，超出时间舍弃，不以超大步或多时钟追赶。

## 公开物理起点

全部在 [config.mjs](config.mjs)，页面可展开原值。
这是本作的待试玩假设，**不是实际车型测量，也不是地平线参数**。

- 原车轮几何给出约 2.018 m 轴距、1.610 m 轮距、.398 m 轮半径；
  800 kg 质量、4200 N 四驱总动力、8.5 m/s² 刹车请求为明确起点。
- 悬挂 rest .30 m、travel .16 m，stiffness 30、compression 4.4、
  relaxation 5.2；Rapier 使用其自身质量相关弹簧／阻尼约定，不能当 N/m。
- `frictionSlip=1.15`、side stiffness 1；不是演示的几乎无限轮胎抓地。
  没有自行堆一套 tire slip / yaw correction 补丁。
- 舵角上限 `0.50 / (1 + (speed/12)^2)` rad；归一化输入每秒
  2.8 渐入、4.5 回正；油门每秒 2.5 渐入、5 回落。
- 刹车 API 接收**每轮冲量上限**，从 `mass × deceleration × dt / 4`
  转换；刹车时引擎力强制为零，因为求解器的非零引擎分支会跳过刹车。

## 已验证 / 待判断

[测试](test.mjs)调用真实 WASM 四轮消费者：接地、起步、松键、刹车优先、
倒车、渐进转向／反打、护栏擦碰、路缘／坡面、无旧速度复位、30/60/120 Hz
帧拆分一致、暂停、退出销毁、局部投影／检查点、面绕序和 HTTP 路由隔离。
测试专用路径跟随器可完整通过 170–740 m，无重置或碰撞；它不进入页面。
[DOM 测试](dom.test.mjs)使用实际 app 与 Rapier，**仅渲染器是 stub**，
验证真实按键、暂停、重置、退出生命周期，不是浏览器或视觉通过。

独立源码审查发现并修正：服务路径拒绝正常请求、道路绕序朝下、车轮反滚、
FOV 不一致、暂停恢复插值回跳。含墙碰的额外 20/30/60/120 Hz 对照状态一致。
首次真实浏览器启动又发现相对天空 URL 被正式初始化契约拒绝：现直接复用
正式 `loadSkyAssets()` 的哈希配置和 `/assets/sky/` 路径，并增加实际
`createSkyPanorama` 初始化消费者回归（纹理加载回调仍为 CPU stub）。

2026-10-27 已在正常 Firefox 中实际进入 Three 画面，以普通键鼠输入、每段
暂停观察起步、制动、转向／反打、碰撞、复位和暂停：较长转向输入撞墙，
重置后短脉冲可继续至约 339 m，观察点均显示四轮接地。退出按钮显示资源
释放提示，随后正常关闭本地服务；未据此宣称底层资源完全无泄漏。

**仍未验收：** 完整弯道连续驾驶、同条件地平线并排对照、主观可控性、声音
和目标硬件性能。上述历史粗输入不足以判断模型优劣，不改参数、不默认采用；仅在新的自动测试与 headless smoke 过门槛后发布旁置入口。

### 人工同弯步骤

1. 固定上述参数与 170 m 起点，W 起步，松 W 后观察惯性。
2. 原路约 320 m 开始入弯：松油／S 制动，A 渐入，弯中适量修正，出口回正再 W。
3. 重置，用相同直道与制动点重复；分别试稍快入弯、松键、反打。
4. 低速轻擦内／外护栏，观察碰撞后是否能重新获得控制；路缘、坡面、翻覆用 R 检查复位。
5. 记录最大可感差距，不用圈速／测试通过替代质量判断。

正常测试不需要公开部署；不能把浏览器启动失败当手感失败，也不能把 CPU
通过当画面／手感通过。只有独立手动对照认可后，才另行决定是否替换正式底座。
