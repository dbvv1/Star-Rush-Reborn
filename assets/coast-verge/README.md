# Coastal low-bush standard consumer

Use the existing whole-set palette and licensed shapes to connect one coast-side patch to the ground, without multiplying repetitive rows. This candidate imports only six named bushes from the original eight-part `verge.glb`. The two fences remain in the preserved source but are not drawn: their long rigid feet need a separately accepted slope/support design.

Source: [original content-set commit ab265593](https://github.com/dbvv1/Star-Rush-Reborn/tree/ab2655930996b9d81f5fb35469669c72b7be28e1/asset-pipeline/content-set), pinned base `verge.glb`, SHA-256 `0479af55bd3bcc937739aa49648ce4ecc41d739279d548af28ead8df7b433d15`. Original Nature 2.1 plant source and Kenney CC0 permission are retained there; local `LICENSE.txt` covers the consumed plant geometry. The source file also contains unconsumed Suburban fences; their CC0 license is retained as `FENCE-LICENSE.txt`. Build rejects changed bytes. No new generator or paid asset.

`coast-verge-runtime.mjs` uses the existing decoder. A rigid 180-degree yaw on the inward bank is a rotation, not one-axis reflection. Whole-footprint terrain-cell extrema bound each planting base: wet or >0.18m relief footprints are rejected; base embeds 0.02m below the minimum (at most 0.20m penetration). Road clearance is 12m and house clearance 1m. The patch is planned after terrain refinement, so it neither changes nor invalidates frozen terrain/house supports. At decoration time current and adjacent chunks are inspected with the original generators; per-node swept AABBs union all four independent house position/scale endpoint combinations. Any such prop AABB within 0.5m suppresses that bush; nothing existing is removed for it. Meshes are lazy, cached, and disposed with the existing coastal rollback. No other public switch, driving input or collision change.

Failure counterexample: placing the entire fence/plant standard at road height on a slope leaves the low end floating or buries the high end. Do not stretch the fence or flatten protected terrain to conceal that failure.

Run `node --test tests/coastal-space.test.mjs tests/coast-street-runtime.test.mjs` and `npm run build`. These cover CPU/source/consumer contracts, not visual acceptance. Actual hardware images, ordinary browser fallback, performance, composition and blind review are outstanding. No coverage, score or default-release credit.
